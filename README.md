# AI 真实老板 · 多轮职场对话训练

一个基于 FastAPI 和 HeroUI 风格前端的 AI 职场对话训练系统，支持视频导入、场景解析、真实老板对话和智能评分。

## 功能特点

- 📹 **多种内容导入方式**：支持本地视频上传、抖音视频链接、直接粘贴文案
- 🤖 **AI 智能处理**：自动提取视频语音、清洗文案、解析职场场景
- 💬 **真实老板对话**：模拟真实老板性格，带情绪识别的多轮对话
- 📊 **综合评分系统**：4轮对话后自动生成详细评分和改进建议
- 🎨 **精美 UI**：HeroUI 风格设计，配合 lucide 图标，视觉体验出色

## 技术栈

### 后端
- **FastAPI**：现代化 Python Web 框架
- **OpenAI SDK**：与 DeepSeek API 交互
- **Whisper**：语音转文字模型
- **yt-dlp**：视频下载工具

### 前端
- **HTML5 + Tailwind CSS**：现代响应式布局
- **Lucide Icons**：精美的图标系统
- **HeroUI 风格设计**：美观的渐变和玻璃态效果

## 安装与运行

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置环境变量

在项目根目录创建 `.env` 文件（如果不存在），添加你的 DeepSeek API Key：

```env
DEEPSEEK_API_KEY=your_deepseek_api_key_here
```

### 3. 启动服务

```bash
python backend.py
```

服务器将在 `http://localhost:8000` 启动。

### 4. 访问应用

在浏览器中打开：`http://localhost:8000`

## 使用说明

1. **选择导入方式**
   - 本地视频：上传 MP4/MOV/AVI 格式视频
   - 抖音链接：粘贴抖音视频 URL
   - 粘贴文案：直接粘贴视频文案或字幕

2. **提取并清洗文字**
   点击「提取文字并清洗」按钮，AI 会自动处理内容

3. **解析场景并开始训练**
   点击「解析场景并开始训练」，AI 将提取职场场景和沟通要点

4. **开始对话训练**
   - 老板会先开场
   - 你可以在输入框回复
   - 共 4 轮对话
   - 老板会根据你的回复表现出不同情绪

5. **查看评分结果**
   4 轮对话结束后，系统会自动生成综合评分，包括：
   - 总分
   - 优点
   - 不足
   - 改进建议

6. **切换场景**
   如果解析出多个场景，可以点击「下一场景」继续训练

## API 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/` | GET | 首页 |
| `/api/video/process` | POST | 处理视频/文本，提取并清洗文字 |
| `/api/video/parse` | POST | 解析内容为职场场景 |
| `/api/chat/boss-start` | POST | 老板开场对话 |
| `/api/chat/boss-reply` | POST | 老板回复用户 |
| `/api/chat/score` | POST | 对话评分 |

## 设计亮点

- **深色主题**：采用深蓝渐变背景，护眼且专业
- **玻璃态效果**：半透明卡片配合模糊背景
- **渐变配色**：蓝色系为主，绿色为辅，视觉层次清晰
- **流畅动画**：淡入效果、脉冲指示、悬停反馈

## 注意事项

1. 确保 `.env` 文件中配置了有效的 DeepSeek API Key
2. 首次运行会下载 Whisper 模型（base 版本约 139MB）
3. 视频处理需要一定时间，请耐心等待
4. 临时文件会在程序退出时自动清理
